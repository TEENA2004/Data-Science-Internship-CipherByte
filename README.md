## 📌 Problem Statement

Classify Iris flower species — Setosa, Versicolor, and Virginica — based on their physical measurements (sepal length, sepal width, petal length, petal width) using a machine learning model.

The Iris dataset is a standard benchmark in machine learning. The goal was to build a classification pipeline from raw data to evaluated model — covering every step of the ML workflow.

---

## ✅ Solution

### 🛠️ Technology Used

| Tool / Library | Purpose |
|---|---|
| Python | Primary language for all processing |
| Pandas | Data loading, cleaning, exploration |
| NumPy | Numerical operations and array handling |
| Scikit-learn | Logistic Regression model, train-test split, evaluation |
| Matplotlib / Seaborn | Data visualization and model performance charts |
| Jupyter Notebook | Interactive analysis and step-by-step execution |

### 🔄 What Was Done — Step by Step

1. Loaded the Iris dataset and explored its structure using Pandas
2. Separated feature columns (sepal/petal measurements) from the target column (species)
3. Encoded species labels and split data into training and test sets
4. Standardized features using StandardScaler
5. Trained a Logistic Regression model on the training set
6. Made predictions on the test set and evaluated results

### 📊 Results

- Dataset: **150 records**, **4 features** (sepal length, sepal width, petal length, petal width), **3 species** (Setosa, Versicolor, Virginica)
- Algorithm: Logistic Regression
- Evaluation metrics used: Accuracy, Precision, Recall, F1-Score, Confusion Matrix
- Model performance was visualized using charts to show species distribution and classification accuracy
